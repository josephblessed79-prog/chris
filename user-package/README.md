# End-user package

**`MOD-Procurement-System.zip`** is the complete offline system for
non-technical users.

## Download
Click `MOD-Procurement-System.zip` above, then the **Download** (raw)
button on the file page.

## Use (Windows)
1. Extract the ZIP (right-click → Extract All).
2. Open the extracted folder and double-click **`index.html`**.
3. It opens in Edge or Chrome. No installation, no internet, nothing to build.

Your work saves as small `.json` case files via the **Save Case** button.
See `USER-GUIDE.md` inside the package for a full walk-through.

> This ZIP is a built artifact of this repository (it bundles the app plus
> the vendored offline libraries). Rebuild it any time with
> `sh tools/make-user-package.sh`.
